For screenshots: drag a rectangle around the person photo, then choose Detect in Selected Area. Face detection works best when the face is large enough. Use Make Background White (AI) after selecting the correct person. Fast mode processes a smaller head-and-shoulders crop; Quality mode uses higher resolution. First run downloads an AI model and needs internet. HD export uses original image pixels when available; sharpening cannot recreate missing facial detail. Later runs can be faster but model/browser caching is not guaranteed. Check hair, ears and shoulders carefully. For passport photos, plain/light backgrounds can be cleaned automatically. Complex backgrounds require a dedicated background-removal model or manual editing; this tool does not guarantee perfect hair/face masking. No facial details are generated or altered. For signatures, auto detection finds dark ink on a light background. For people, MediaPipe face detection is attempted when internet is available; browser detection is a fallback. Face detection does not remove complex backgrounds. Always review the blue crop box before printing.
